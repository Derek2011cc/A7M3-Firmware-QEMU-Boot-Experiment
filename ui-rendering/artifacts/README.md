# 软件重放产物

这些 PNG/GIF 是 QEMU 内软件解释器的输出：**不是**真机截图，也**不是**正确渲染。
它们用于说明“命令流确实是 UI 绘制”，以及当前还差什么。

| 文件 | 模式 | 内容/观察 |
|---|---|---|
| `surf2-rgba4444.png` | 直投 | 一帧合成：橙色砖纹条在顶部，底部有点阵/字形碎片 |
| `surfg-rgba4444.png` | 直投（另一帧） | 与上类似，位置不同 |
| `c60-rgba4444.png` | 居中（`A7M3_SUGI_CENTER=1`） | 顶部一行小图标、中部橙色条、底部面板；结构最像菜单 |
| `menu-contact-sheet.png` | 居中，60 帧取 30 | 橙色条滑动、黑色圆角矩形出现/消失的动画 |
| `menu-anim.gif` | 居中，60 帧 | 同上，可播放 |
| `texture-22772380-brick.png` | 事后 QMP 转储 | `0x22772380` 的 56×48 橙色砖纹（RGBA4444 线性视图） |
| `texture-22773900-dump-time.png` | 事后 QMP 转储 | `0x22773900` 的 64×56 内容：黑底灰条；绘制时刻该地址可能被复用为砖纹 |

## 生成方式

- `.raw` 帧：QEMU 软件光栅在每次实际绘制后写 `frame_XXXX.raw`
  （640×480 RGBA4444，614,400 B），由 `A7M3_SURF_DIR` 指定目录；
- PNG/GIF：`../scripts/analysis/gpu/frames2gif.py <dir> <prefix>`；
- 单张 PNG：`../scripts/analysis/gpu/conv_bg.py <raw> <png>`。

## 判读注意事项

- 目标表面没有在每帧前清空；帧是**累积合成**的结果，后面的帧包含前面绘制的内容；
- 纹理采样目前是“整张纹理拉伸 + wrap”，没有顶点/UV；
- 纹理内存在运行时复用：事后 QMP dump 到的同一地址可能已不是绘制时刻的内容；
- 坐标模式（直投/半/居中）尚未证实，不要把这些图当成坐标空间的证据；
- 文字不可读是预期内的：字形纹理的格式/采样还没解出。
